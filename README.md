# Decision-tree-Random-Forest-

This repository focuses on implementing and understanding Decision Trees and Random Forests.

## Objective

The objective of this task was to learn about tree-based models for classification and regression, specifically Decision Trees and Random Forests, using Scikit-learn and Graphviz.

## Task Breakdown

The task involved the following steps:

1.  **Training a Decision Tree Classifier:** Trained a basic Decision Tree model on the dataset.
2.  **Decision Tree Visualization:** Attempted to visualize the trained Decision Tree using Graphviz (note: visualization code is included but requires Graphviz installation).
3.  **Overfitting Analysis and Control:** Analyzed the initial Decision Tree for overfitting and implemented strategies to control tree depth to improve generalization.
4.  **Random Forest Training:** Trained a Random Forest Classifier.
5.  **Accuracy Comparison:** Compared the performance (accuracy) of the Decision Tree and Random Forest models.
6.  **Feature Importance Interpretation:** Interpreted the feature importances from the trained Random Forest model to understand which features were most influential.
7.  **Cross-Validation Evaluation:** Evaluated both models using cross-validation for a more robust performance assessment.

## How to Run the Code

1.  Make sure you have Python installed.
2.  Install the necessary libraries:
    ```bash
    pip install pandas scikit-learn matplotlib graphviz
    ```
3.  Install Graphviz and add it to your system's PATH (required for tree visualization).
4.  Place the dataset file (`heart_disease_dataset.csv`) in the same directory as the Python script, or update the script with the correct path.
5.  Run the Python script from your terminal:
    ```bash
     decision_trees_random_forests.py
    ```
